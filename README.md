# RupeeFX Terminal (Prototype)

A lightweight, single-page SaaS prototype for forex and gold analysis aimed at Indian traders.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Included modules

- Markets board + correlations
- Multi-chart desk shell
- Analyst feed
- Economic calendar
- COT & macro module
- Backtesting lab simulator
- Trading journal form + live entries
- Community room overview
